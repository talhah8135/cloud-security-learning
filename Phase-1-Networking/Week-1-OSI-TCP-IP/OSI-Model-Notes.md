OSI Model – My Networking Notes

What I Learned

The OSI model helps explain how computers communicate over a network. It divides network communication into seven layers. Each layer has its own responsibility.

I studied all seven layers and learned how they work together when data travels between devices.

The Seven Layers

Layer

Name

What I learned

7

Application

Where network services such as HTTP, HTTPS and DNS are used by applications.

6

Presentation

Deals with data format, encoding and encryption.

5

Session

Manages communication sessions between applications.

4

Transport

Handles end-to-end communication using TCP and UDP.

3

Network

Uses IP addresses and handles routing between networks.

2

Data Link

Works with MAC addresses and Ethernet frames.

1

Physical

Carries bits through cables, connectors and physical signals.
