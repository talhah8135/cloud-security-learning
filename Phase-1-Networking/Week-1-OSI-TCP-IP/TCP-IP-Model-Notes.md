TCP/IP Model – My Networking Notes

What I Learned

The TCP/IP model explains how devices communicate over the internet and other networks.

Unlike the OSI model, which has seven layers, the TCP/IP model has four layers.

I learned that each layer has a different responsibility, and together they help data travel from one device to another.

How the Layers Work

1. Application Layer

Provides services used by applications.

Examples include HTTP, HTTPS and DNS.

Combines the functions of OSI Layers 5, 6 and 7.

2. Transport Layer

Handles communication between devices.

TCP provides reliable and ordered delivery.

UDP provides connectionless communication.

Uses port numbers to identify applications and services.

3. Internet Layer

Handles logical addressing using IP addresses.

Helps packets travel between different networks.

Routers operate at this level of communication.

4. Network Access Layer

Handles communication over the local network.

Works with Ethernet frames and MAC addresses.

Includes the physical transmission of data.

What I Understood

Both models help explain network communication.

The OSI model divides communication into seven layers, while TCP/IP groups the responsibilities into four layers.

TCP/IP is widely used in real-world networking and internet communication
