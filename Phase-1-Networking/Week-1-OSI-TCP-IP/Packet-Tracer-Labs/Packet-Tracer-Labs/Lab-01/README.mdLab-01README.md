# Packet Tracer Labs

This folder contains my practical networking exercises created using Cisco Packet Tracer.

## Lab 01 – Two PC Network

**File:** `Lab01_Two_PC_Network.pkt`

### Objective
Build a basic network connecting two computers and practise assigning IP addresses and testing connectivity.

### Devices
- PC2
- PC3

### Practical skills
- Connecting computers using Ethernet.
- Configuring IP addresses.
- Testing connectivity using the ping command.

### Learning outcome
Practised basic device connectivity and network communication using Cisco Packet Tracer.

Further configuration details and test results will be documented after reviewing the original lab.
